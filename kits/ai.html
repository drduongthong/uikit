1. Phân tích yêu cầu: Viết custom hook debounce trong React với TypeScript.
2. Xác định các dependency: value (generic T) và delay (number).
3. Quản lý state debouncedValue, khởi tạo với giá trị ban đầu.
4. Thiết lập useEffect với setTimeout và trả về cleanup function clearTimeout để tránh memory leak.

Dưới đây là implementation chuẩn của custom hook useDebounceValue bằng TypeScript:

useDebounceValue.ts 
import { useState, useEffect } from 'react';

/**
 * Hook trì hoãn cập nhật giá trị sau một khoảng thời gian chờ (ms)
 */
export function useDebounceValue<T>(value: T, delayMs: number = 300): T {
  const [debouncedValue, setDebouncedValue] = useState<T>(value);

  useEffect(() => {
    const timer = setTimeout(() => {
      setDebouncedValue(value);
    }, delayMs);

    // Dọn dẹp timer nếu giá trị thay đổi trước khi hết delay
    return () => clearTimeout(timer);
  }, [value, delayMs]);

  return debouncedValue;
}

💡 Điểm tối ưu: Sử dụng TypeScript Generics <T> đảm bảo an toàn kiểu dữ liệu tự động theo giá trị truyền vào (string, number, array, object).
