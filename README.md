## 💎 Tiêu chuẩn Thiết kế (Design Principles)

1. **Độ hoàn thiện 100% (High Fidelity & Real Polish):** Tất cả các thành phần tương tác (tabs, nút bấm, slider, modal, audio, filter) đều phản hồi mượt mà và có logic hoạt động thực tế.
2. **Audio Feedback (Web Audio API Synthesizer):** Không phụ thuộc tài nguyên MP3 bên ngoài, tự động tổng hợp âm thanh laser, còi xe, âm báo chiến thắng trực tiếp trong trình duyệt.
3. **Typography Tiếng Việt Chuẩn 100%:** Sử dụng các font chữ Google Fonts hàng đầu: Plus Jakarta Sans, Be Vietnam Pro, Space Grotesk, Chakra Petch và JetBrains Mono.
4. **Light & Dark Mode Đồng Bộ:** Cung cấp màu nền và tương phản được căn chỉnh chuẩn mực cho từng ngành nghề đặc thù.
5. **Zero External Build Dependencies:** Chạy trực tiếp chỉ cần mở tệp HTML trong bất kỳ trình duyệt hiện đại nào mà không cần cấu hình Node.js hay NPM phức tạp.

## ⚡ Khởi chạy nhanh

Mở trực tiếp tệp [`index.html`](file:///Users/lybinhson/00.drduongthong/opencode/ui-kit/index.html) trong trình duyệt hoặc sử dụng local server:

```bash
# Sử dụng Python built-in server
python3 -m http.server 8080

# Hoặc dùng npx serve
npx serve .
```

Sau đó truy cập `http://localhost:8080` để trải nghiệm toàn bộ hệ thống Showroom.
