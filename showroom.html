Đổi theme, palette trong vài giây với CSS variables. Swatch dưới đây tương tác hover.

Bắt đầu

Sử dụng trong 3 bước

Không cần build — mở file HTML, thêm CSS/JS và bắt đầu. Token-driven giúp đồng bộ toàn hệ thống.

<!-- 1. Link tokens + components -->
<link rel="stylesheet" href="styles/tokens.css" />
<link rel="stylesheet" href="styles/components.css" />
 
<!-- 2. Apply theme -->
<html data-theme="dark">
 
<!-- 3. Dùng component -->
<button class="btn btn--gold btn--lg">Gold Action</button>
